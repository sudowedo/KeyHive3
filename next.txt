## 🛠 What you need to do next
1. Generate a secure 32-byte master key and set `KEYHIVE_MASTER_KEY_BASE64` in `.env`.
   - Example command:
     - `openssl rand -base64 32`
2. Create the PostgreSQL database (if not already):
   - `createdb keyhive`
3. Apply migration SQL:
   - `psql "$DATABASE_URL" -f backend/migrations/001_initial_postgres.sql`
4. Create your first project (required before creating master keys/subkeys):
   - `POST /api/projects` with `{ "name": "Default Project" }`
5. Ensure Redis is running and reachable at `REDIS_URL`.
6. Install backend dependencies locally (network/policy permitting):
   - `cd backend && npm install`
7. Start backend:
   - `npm start`
8. For project-scoped endpoints, send `x-project-id` header (from step 4 project id).
9. Seed at least one master key (`POST /api/master-keys`).
10. Create a subkey (`POST /api/subkeys`).
11. Test rate limiting:
   - Hit `/v1/chat/completions` 3 times within 60s with same subkey token.
   - Expect first 2 pass, 3rd returns 429.
