Production-grade API governance

Share AI access safely without leaking provider keys.

KeyGate is a project-scoped API gateway: issue subkeys, enforce quotas/rate limits, monitor requests, and keep master keys encrypted at rest with AES-256-GCM.

99.9%
Target operational reliability
Storage: PostgreSQL + Redis
Encryption: AES-256-GCM
Health: 90-day status bars

Project Isolation

Every master key, subkey, log, and quota request is scoped by project_id to prevent cross-workspace leakage.

Encrypted Secrets

Master keys and subkey tokens are encrypted using AES-256-GCM with authenticated ciphertext, IV, and auth tag.

Operational Visibility

Daily health snapshots, request metrics, and persistent backend error logs for faster incident response.

How it works

Client SDK (subkey) -> KeyGate Proxy (/v1/chat/completions) -> Validate subkey + status + expiry + allowed models -> Enforce rate limit + request quota -> Resolve encrypted master key (server-side only) -> Forward request upstream provider -> Write request log + latency + token usage

Proofs / Security guarantees

  • No plaintext provider key in frontend APIs
  • Subkey full token shown once on creation flow
  • Project-scoped data access via x-project-id guard
  • Schema drift check blocks broken startup

Encryption details

Algorithm: AES-256-GCM. Key material from KEYHIVE_MASTER_KEY_BASE64 (32-byte). Stored fields include ciphertext, IV, auth tag, and key version metadata for rotation readiness.
